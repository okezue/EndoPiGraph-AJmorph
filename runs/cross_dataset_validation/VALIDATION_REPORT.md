# Cross-Dataset Validation Report for EndoPiGraph-AJmorph

## Executive Summary

This report presents results from validation of EndoPiGraph-AJmorph across multiple datasets. **Important methodological notes** are included regarding the interpretation of cross-dataset "transfer" metrics.

---

## ⚠️ Critical Methodological Note on "Transfer Accuracy"

### What the Transfer Test Actually Measures

The cross-dataset transfer test trains a RandomForest classifier on features + heuristic labels from one dataset, then tests on another dataset. **Both training and test labels are generated by the same EndoPiGraph heuristic classifier (`infer_ajmorph_label_heuristic`).**

This means:
- **High accuracy (0.97-1.0) does NOT validate biological accuracy**
- It only shows that a ML model can learn to replicate the heuristic rules
- This is a test of **heuristic consistency**, not biological validity

### What Would Be Needed for True Validation

To properly validate classification accuracy, you would need:
1. **Manual expert annotations** on a subset of edges (gold standard)
2. **Comparison of EndoPiGraph labels vs expert labels**
3. **Inter-rater reliability** between multiple experts

### Correct Interpretation

| Claim | Interpretation |
|-------|----------------|
| "0.97-1.0 transfer accuracy" | ❌ Does NOT mean "EndoPiGraph is accurate" |
| "0.97-1.0 transfer accuracy" | ✓ Means "heuristic produces consistent labels across datasets" |
| "0.97-1.0 transfer accuracy" | ✓ Means "ML can learn the heuristic decision boundaries" |

### Why Consistency Matters (But Isn't Sufficient)

Consistency across datasets IS valuable because:
- It shows the heuristic is reproducible and not data-dependent
- It means results from different labs/datasets are comparable
- It provides a stable basis for comparative studies

But consistency ≠ biological accuracy. The heuristic could consistently assign wrong labels.

### Key Findings

1. **Intensity Scaling**: Results are **perfectly stable** (Cohen's d = 0.000) to ±20% intensity changes due to Otsu adaptive thresholding.

2. **Noise Robustness**: Results stable to 5-10% Gaussian noise (|d| < 0.5 for all metrics).

3. **Parameter Sensitivity**: Threshold and dilation changes have small but acceptable effects (|d| < 0.4).

4. **Blur Sensitivity**: `cluster_count` is sensitive to blur (d > 0.5) because blur merges adjacent clusters. Other metrics remain stable.

### Overall Stability

**28/30 (93.3%)** parameter-metric pairs are stable (|Cohen's d| < 0.5)

Only `cluster_count` under blur conditions showed medium-to-large effects, which is expected since blur physically merges adjacent junction fragments.

## 2. VALID Cross-Dataset Transfer: Condition Prediction

### Proper Methodology

Instead of the circular heuristic→heuristic test, we use **experimental conditions** as ground truth labels:
- Labels: Shear stress condition (static, 6dyne, 18dyne)
- Task: Predict condition from junction features
- This is valid because conditions are independent of EndoPiGraph

### Results

| Test | Accuracy | N edges |
|------|----------|---------|
| 5-fold CV (random splits) | **77.6%** | 16,285 |
| Leave-one-image-out | **80.6%** | 16,285 |

### Feature Importances for Condition Prediction

| Feature | Importance |
|---------|------------|
| aj_mean_intensity | 0.264 |
| aj_occupancy | 0.181 |
| aj_std_intensity | 0.115 |
| aj_cluster_area_mean | 0.096 |
| aj_thickness_proxy | 0.081 |

### Interpretation

- **77-80% accuracy is biologically meaningful** - features capture condition-related variance
- **Not 100%** (and shouldn't be) - individual variation, other factors exist
- **Generalizes across images** - leave-image-out ≈ random CV
- **Mean intensity and occupancy** most predictive of shear condition

### What This Validates

✓ EndoPiGraph features capture biologically relevant information
✓ Shear stress affects junction morphology (known biology)
✓ Features generalize across images

### What This Does NOT Validate

✗ That heuristic morphology labels match expert judgment
✗ Cross-dataset transfer to different cell types (needs separate testing)

## 5. Blur Sensitivity and Mitigation

### The Problem

`cluster_count` is sensitive to blur (Cohen's d > 0.5) because Gaussian blur physically merges adjacent junction fragments.

### Solution: Blur-Robust Mode

EndoPiGraph v1.1 provides blur-robust classification:

```python
from endopigraph import (
    compute_blur_robust_features,
    blur_robust_classifier,
    estimate_blur_score,
)

# Check image quality
score = estimate_blur_score(image)
print(f"Blur score: {score}")  # >100 = sharp, <50 = blurry

# Use blur-robust classification
features = compute_blur_robust_features(marker, mask, threshold)
classification = blur_robust_classifier(features)
```

### Blur-Robust Stability Results

| Method | Classification Stability |
|--------|--------------------------|
| Simple Baseline | 99.9% |
| **Blur-Robust EndoPiGraph** | **93.3%** |
| Original EndoPiGraph | 89.1% |
| Junction Mapper equivalent | 46.9% |

## 6. Conclusions

### Strengths

1. **Reproducible**: Heuristic produces consistent labels (useful for comparative studies)
2. **Robust to imaging variations**: 93% of parameter-metric combinations are stable
3. **Excellent intensity invariance**: Otsu thresholding provides perfect stability
4. **Blur-robust mode available**: 93.3% classification stability under blur

### Limitations

1. **No ground truth validation**: Classifications are heuristic, not validated against expert annotations
2. **Blur sensitivity**: Original `cluster_count` metric changes with blur
3. **Class definitions are heuristic**: Boundary thresholds between classes are arbitrary

### Recommendations for Papers

1. **Do NOT claim "0.97 transfer accuracy"** - this is circular
2. **DO claim "consistent reproducible classifications across datasets"**
3. **Acknowledge** that classifications are heuristic pending expert validation
4. **Use blur-robust mode** for variable-quality data
5. **Report effect sizes** (Cohen's d) alongside p-values
